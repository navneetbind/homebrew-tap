# homebrew-tap

    brew install navneetbind/tap/claude-powertools
    powertools open

Upgrade with `brew upgrade claude-powertools`. Source: https://github.com/navneetbind/claude-powertools

    brew install --cask navneetbind/tap/verse

Synced YouTube Music / Spotify lyrics in the macOS menu bar. Upgrade with `brew upgrade --cask verse`. Source: https://github.com/navneetbind/verse
